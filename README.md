# Установка приложения «Учёт»

## 1. Google Таблица (хранилище данных)
1. Откройте sheets.google.com → создайте пустую таблицу.
2. Меню **Расширения → Apps Script**.
3. Удалите всё в редакторе, вставьте содержимое файла `Code.gs`.
4. В строке `const SECRET = '...'` замените `ЗАМЕНИТЕ_НА_СВОЙ_ПАРОЛЬ` на свой пароль (латиница и цифры, кавычки оставьте). Нажмите 💾.
5. **Развернуть → Новое развёртывание** → шестерёнка → **Веб-приложение**.
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
6. **Развернуть** → разрешите доступ (Дополнительно → Перейти на страницу → Разрешить).
7. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).

**Если потом меняете код или пароль:** Развернуть → **Управление развёртываниями** → карандаш → Версия: **«Новая версия»** → Развернуть. Ссылка останется прежней. («Новое развёртывание» даст новую ссылку, и её придётся заново вставить в приложение.)

## 2. GitHub Pages
Репозиторий: `Ersaiyn-go/PanaSana`.
1. **Add file → Upload files**: перетащите `index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png` → **Commit changes**.
2. **Settings → Pages**: Source = *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты приложение откроется по ссылке:
   **https://ersaiyn-go.github.io/PanaSana/**

`Code.gs` и `README.md` на GitHub загружать не нужно. Пароль и ссылка скрипта в GitHub не попадают, они вводятся только в приложении.

## 3. Подключение
1. Откройте ссылку на телефоне → вкладка **⚙** → вставьте URL скрипта и пароль → **Сохранить и синхронизировать**.
2. Установите на экран:
   - Android (Chrome): меню ⋮ → **Установить приложение**.
   - iPhone (Safari): **Поделиться → На экран «Домой»**.

## 4. Перенос данных из старой версии
В старом приложении: **Счета → Данные для переноса** → скопируйте текст. В новом: **⚙ → Перенос** → вставьте → Импортировать. Повторный импорт тех же данных не создаёт дублей.

## Как работает
- Без интернета приложение открывается и принимает операции; отправка в таблицу идёт при появлении сети (и автоматически повторяется каждые 2 минуты).
- На Android выписку можно отправить через **Поделиться → Учёт**: текст или PDF подставится в «Разбор».
- **PDF-выписка:** «Разбор» → «Загрузить PDF-выписку». Для первого чтения PDF нужен интернет. Уже сохранённые операции пропускаются.
- **PIN:** ⚙ → PIN-код. Спрашивается при открытии и после 30 секунд в фоне. Защищает вход, но не шифрует данные.
- Таблицу можно смотреть и править вручную: лист «Операции» и лист «Счета».

## Своя разбивка счетов (лист «Настройки»)
При первом подключении скрипт сам создаёт в таблице лист **«Настройки»** с тремя колонками. Каждая строка — одна кнопка при разборе:

| Группа | Категория | Счёт |
|---|---|---|
| Личное | Еда | Личное |
| Бизнес | Доставка | Доставка |
| Бизнес | На сайт | Доставка |

- **Группа** — большие кнопки на первом шаге разбора и разделы в отчёте (БИЗНЕС, ЛИЧНОЕ).
- **Категория** — кнопки на втором шаге.
- **Счёт** — с какого счёта списывается. Квадраты на главной строятся из этой колонки.
- **Первая группа** — главная: её реальный расход крупно в «Анализе», её счёт выделен цветом.

Поменяли строки → в приложении ⚙ → **«Обновить данные из таблицы»**. Код трогать не нужно. Уже сохранённые операции не меняются.

## Приложение для другого человека
1. Он создаёт **новую пустую** таблицу и делает шаг 1 (вставляет `Code.gs`, ставит свой пароль, разворачивает, копирует ссылку /exec). Не копируйте свою таблицу: в ней ваши операции.
2. Открывает ту же ссылку приложения https://ersaiyn-go.github.io/PanaSana/ → ⚙ → вставляет **свою** ссылку и пароль.
3. В его таблице появится лист «Настройки» — он меняет строки под себя и нажимает «Обновить данные из таблицы».
Данные каждого хранятся только в его таблице.

## Обновление
**Add file → Upload files**, загрузите заново изменённые файлы (заменятся) → Commit. Приложение обновится при следующем открытии с интернетом. Если поменялась иконка, на телефоне удалите ярлык и добавьте заново.
